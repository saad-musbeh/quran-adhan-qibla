# Android icon

`android-icon-v1.png` is the Android launcher/adaptive icon: a cream open Quran, gold direction pointer and crescent on forest green. Created with the built-in ImageGen tool, then copied without pixel edits. Expo generates the native launcher sizes. The iOS icon remains pending.

Final ImageGen prompt:

> Create the final Android launcher icon from this concept, redrawing it cleanly rather than preserving its rough pixels. One square app icon asset, completely opaque, edge-to-edge SOLID dark forest green background #17382B. Center a simple flat open Quran book with two solid warm ivory page shapes #FAF7EF, one muted gold #DBAB68 central spine ending in an upward compass point, muted-gold lower book cover, and a small gold crescent above. The same arrangement as the input. Every shape must be smooth, filled, crisp and vector-like. No gradients, no brush texture, no stray dots or specks, no halos, no shadows, no lines, no text. The whole emblem occupies ONLY the central 54% of the square canvas, with generous equal green margins. All corners must be filled with the same green, no rounded-square tile, no transparency. Production-quality clean app icon, no mockup, no watermark.

`notification-icon.svg` is a separately drawn white book/direction silhouette for Android's monochrome notification area. ImageMagick renders its transparent PNG; Expo generates the native density variants.
