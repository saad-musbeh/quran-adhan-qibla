# Downloadable tafsir editions

Tafsir is published commentary, never generated by the app. In the catalogue
and download manager, editions in the selected UI language appear first;
Arabic editions remain visible in every language. No ordinary Quran translation
is presented as a tafsir. Book text is downloaded only on request to private
app storage; it is not bundled in the APK or source repository.

The reader shows the verse and commentary without an attribution footer.
**Settings → Credits / المصادر وحقوق النشر** contains publisher, source,
version, licence and source links. Catalogue rows show a short title, author,
download status and a short date; date details distinguish composition,
first publication where documented, and the edition actually used.

The four existing Arabic QuranEnc editions remain unchanged. New Quranpedia
archives use the official [versioned dumps](https://api.quranpedia.net/dumps)
with the original SHA-256 checksums recorded in
[the source manifest](../assets/tafsir/quranpedia-sources-2026-08-10.json).
Their per-file version is 2026-08-10, even though the overall service manifest
was generated later. Their [data licence](../assets/tafsir/QURANPEDIA-LICENSE.md)
allows app use and requires attribution and a version for redistributed datasets.

`scripts/import-quranpedia-tafsir.py` turns source HTML into readable plain text,
preserves source paragraph order/verse references, and pools repeated paragraphs.
For example, Safwat's 163 MB source JSON becomes a 7.9 MB uncompressed indexed file.
This avoids recreating repeated large passages in device memory. The compact
archive contains its source licence, edition metadata and original dump hash.
Archives are separate release assets; source text is never added to Git.

Downloads check compressed SHA-256 and byte sizes before decoding, then check
uncompressed size, source identity/version, language, record counts, uniqueness
and canonical verse bounds. Only the complete verified source edition is made
available; temporary files are removed on cancellation/failure. Existing schema 1
and schema 2 private downloads remain readable.

A source may have no separate entry for an ayah. Jalalayn contains 6224 mapped
records, Ibn Kathir 6057 (three records have empty content), Fath al-Qadir 6214;
the other three official dumps map 6236 verses. Missing entries show an explicit
no-commentary message and offer another book; the app never borrows another
verse's commentary or fills gaps. Source paragraphs attached by the provider
are retained, including introductions and cross references.

## Dates

870 AH is the completion year of Suyuti's portion of Jalalayn, as recorded in
the [manuscript catalogue](https://www.alukah.net/triqi/7/18576/), and is labelled
**composition**, not first printing. The supplied classical years are not
asserted as first publication dates:671 AH is Qurtubi's death year, for example.
Where the source only documents a later print edition, the row uses **Ed. / ط.**
with that edition's year. Undocumented first-publication dates are omitted from
reading and catalogue subtitles. Shawkani is identified by the source as
Muhammad ibn Ali, not Badr al-Din.

## QuranEnc translated tafsir

Al-Mukhtasar's published translations and Uzbek Muyassar use the existing
QuranEnc endpoints and retain their text, footnotes, publisher and edition
metadata without edits. Source releases are verified against the official
catalogue before download. The full 114-chapter source inspection found one
empty Spanish Mukhtasar translation at 59:24; this explicit pinned exception
is retained as empty source data and shown as no separate commentary.
Other books still require nonempty canonical per-verse records. Grouped Saadi
editions retain the source passages and their supplied explanatory paragraphs.
Empty structural rows never become invented commentary.

[QuranEnc's reuse terms](https://quranenc.com/ar/home/api/) require unchanged
content, publisher/source/version identification, retaining edition metadata,
and updates to newly released editions. Credits supplies these acknowledgements.

## Published translations and source inspection

There are 36 catalogue editions: 11 Arabic books and 25 published non-Arabic
editions in 21 of the app's supported languages. Al-Mukhtasar is available in
French, Spanish, Turkish, Azerbaijani, Bosnian, Uzbek, Kyrgyz, Indonesian,
Chinese, Persian, Sorani Kurdish, Pashto, Hindi, Bengali, Malayalam, Tamil and
Fulfulde. Uzbek also has Muyassar. Published Saadi translations are available
in Turkish, Russian, Indonesian, Persian, Urdu and Swahili. English uses
Tazkirul Quran by Maulana Wahiduddin Khan, edited by Farida Khanam.

Every QuranEnc chapter in each new edition was inspected on 12 October 2026.
The per-verse editions all contain 6236 canonical records. The six Saadi
sources have 7150 source rows and 1742 passage blocks each, with complete range
coverage. Source empty rows are allowed only for these specifically identified
editions. Turkish 2:220 has no separate nonempty interpretation block; the
publisher's 2:219 paragraph explicitly discusses 219–220. This text is retained
at its original reference without copying it to the missing block.

English Tazkirul's translation and commentary are explicitly copyright free
in the original [Goodword/CPS publisher PDF](https://cpsglobal.org/sites/default/files/2025-01/Quran-Commentary.pdf).
Its first printing is dated 2011 Gregorian, with no precise month/day to support
a single Hijri year. The opening commentary was compared with that PDF.
Qurtubi's opening basmala paragraph was compared with the official Quran.com
resource 90; editions differ in introductions and orthography. No claim is
made that they are identical editions.

The two compact mirror sources pin Git commit
`9ae590abdaaa38462f4f91cc141903aa6f72cc23` and preserve the full MIT notice,
original 114-chapter hash manifest, publisher permissions and source identity.
Regenerate using `scripts/import-tafsir-mirror.py` with explicit cache/output
directories. The [metadata manifest](../assets/tafsir/tafsir-mirror-sources.json)
records exact compressed and uncompressed sizes/hashes. The compact archive
stores repeated source texts once but preserves every source verse mapping.
