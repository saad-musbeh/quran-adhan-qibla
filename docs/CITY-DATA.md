# Offline city catalogue

`src/data/cities.json` contains **224,763 populated places across 245 countries and territories**, with sourced WGS84 latitude and longitude. It is an offline fallback for choosing a city before map selection or manual coordinates. All eligible places from GeoNames `cities500` are included: there are no country quotas or religion-based exclusions. This supports locations in countries with both majority and minority Muslim populations without making unsupported claims about any city's religious composition.

The catalogue is generated by `scripts/build-city-catalogue.py`. Raw downloads stay in a temporary directory and are not added to the repository. The generated city JSON is approximately 29.5 MB before mobile bundling/compression.

The JSON contains nested arrays of at most **4,096 records**, which `src/domain/cities.ts` flattens with ordinary runtime `push` calls. A single compiled array literal containing the full catalogue crossed Hermes' 65,535-element dense-array boundary and caused the 0.4.7 Android release to fail during city-index initialization. Bounded literals avoid that compiler/runtime boundary without dropping or changing places. No function receives the entire catalogue as spread arguments. Rebuilding the catalogue preserves this format.

## Sources and method

- [GeoNames `cities500.zip`](https://download.geonames.org/export/dump/cities500.zip) supplies populated-place IDs, primary names, ASCII transliterations, country codes, coordinates, timezones and population ranking. The documented extract covers places with population above 500 or administrative seats down to level 4. The builder includes feature codes PPLC, PPLA through PPLA4, PPL and PPLS. PPLX neighborhoods, historical locations and abandoned places are excluded. It keeps every eligible record with a known country code and valid coordinates, without repeating records to fill a quota.
- [GeoNames `alternateNamesV2.zip`](https://download.geonames.org/export/dump/alternateNamesV2.zip) supplies Arabic aliases (`ar`) where available. Historic aliases are ignored; the first preferred alias takes precedence over ordinary aliases. Primary city labels and ASCII transliterations are supplied by GeoNames rather than invented translations. When no Arabic alias exists, the source primary name is displayed.
- [GeoNames `countryInfo.txt`](https://download.geonames.org/export/dump/countryInfo.txt) supplies country codes and English country names. The names are trimmed of surrounding whitespace. Arabic country names are generated from Node.js 22's CLDR-backed `Intl.DisplayNames` and bundled in the country records, so the app needs no DisplayNames polyfill.

Countries are ordered by their English source name. Within each country, records are ordered by descending GeoNames population and then ascending GeoNames ID. `cityCount` reports the actual number of eligible records. There is no target count, and no demographic dataset is needed for inclusion. The source threshold means some very small settlements are absent; map selection and manual coordinates remain available for them.

Search checks primary names, sourced ASCII transliterations and available Arabic aliases. It ignores case, Latin accents and Arabic vowel marks, and handles common Arabic alef variants. Exact matches appear before names beginning with the query, followed by substring matches. Country browsing uses an index; normalized search aliases are cached. Search returns all matching records rather than stopping after fifty. The UI starts with eight visible results and reveals further results with **Show more**, so a broad query or a country's full catalogue does not render thousands of rows at once.

## Regeneration

Run `python scripts/build-city-catalogue.py` with network access. It uses Python's standard library and the project's Node.js 22 runtime for Arabic country labels, writes `src/data/cities.json` and `src/data/countries.json`, and does not retain the source archives. The Arabic alias archive is approximately 205 MB compressed; it is only a build input, not bundled with the app. Search and display helpers are exported from `src/domain/cities.ts`.

Run `node --experimental-strip-types --test src/domain/cities.test.ts` to verify IDs, coordinates, country counts, small-territory coverage, cities beyond the former quotas, Arabic/transliteration search, result ranking and access beyond fifty matches. Also run the project's full `npm run check` and `npm run export:mobile` before delivering changes. Desktop search checks and mobile exports do not establish real-device memory usage or responsiveness for the larger catalogue.
